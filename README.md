# Sidharth Gupta — Premium Developer Portfolio

Built with React, Vite, Framer Motion and Lucide React.

## Included
- Recruiter-focused hero and role positioning
- Responsive mobile navigation
- Skills grouped by Frontend / Backend / Database / AI & ML
- Product-style project previews
- Working Live Demo and GitHub links where available
- Project case-study modal
- Edorer experience with both internship projects
- Education and CGPA
- Certifications & activities
- GitHub snapshot
- Resume view/download
- Contact form using mailto
- Custom cursor glow and responsive motion
- Mobile-first responsive layout

## Run
npm install
npm run dev

## Production
npm run build
npm run preview

## Deploy
Build command: npm run build
Output directory: dist
